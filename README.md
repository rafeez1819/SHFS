🎓 FAQ: Common Questions
Q: Is this too complex for normal users?
A: No! Users see a normal folder/drive. All security happens automatically in the background.
Q: What if I forget my password?
A: SHFS uses cryptographic keys sealed in hardware, not passwords. Recovery requires physical access to authorized hardware + cryptographic key shares.
Q: Can law enforcement access encrypted data?
A: Only with proper legal authorization AND physical access to the sealed TPM chip. No backdoors exist.
Q: What happens if the TPM chip fails?
A: We implement multi-threshold key recovery (3-of-5 Shamir secret sharing). Key shares stored in: TPM, cloud KMS, and offline USB. Any 3 can recover.
Q: How do I migrate data to a new computer?
A: Use shfs-migrate which re-seals keys to new TPM while maintaining cryptographic chain of custody.
Q: Does it work on older computers?
A: Requires TPM 2.0 (2014+) and AES-NI (2010+). 99% of business computers qualify.
Q: What's the performance impact?
A: < 5% overhead on modern CPUs with hardware acceleration. Barely noticeable in real-world use.
Q: Can it be hacked?
